# Instruções para Upload de Ícones

## 📂 Salvar neste diretório: `public/icons/`

### Ícones necessários:

1. **coffee-bean.png**
   - Fonte: arquivo 808799.png (renomear)
   - Uso: Ícone de grão de café para sidebar e cafés
   - Tamanho: 64x64px ou 128x128px
   - Formato: PNG com fundo transparente

2. **roaster-icon.png**  
   - Fonte: arquivo Roaster-Icon (renomear)
   - Uso: Logo principal ao lado de "Studio Grão"
   - Tamanho: 64x64px ou 128x128px
   - Formato: PNG com fundo transparente
